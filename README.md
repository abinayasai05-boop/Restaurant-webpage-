Restaurant Webpage

Description

A simple Restaurant Webpage developed using HTML, CSS, and JavaScript. The website displays restaurant information, menu items, contact details, and a special offer popup.

Live webpage :https://abinayasai05-boop.github.io/Restaurant-webpage-/#about

Features

- Home page with welcome section
- Menu display
- About Us section
- Contact information
- Special offer popup using JavaScript
- Simple and responsive design

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Open "index.html" in a web browser.
2. Navigate through the webpage sections.
3. Click the View Today's Offer button to see the special offer.

Conclusion

This project demonstrates the basics of frontend web development using HTML, CSS, and JavaScript to create an interactive restaurant website.
